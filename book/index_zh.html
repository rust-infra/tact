Agent 开发教程（中文）

本目录收集 Tact 及相关 agent 运行时的设计说明与动手教程。本书只有中文版：英文册已于 2026-09-30 整体删除。_zh.html 后缀是历史命名，不再是「与英文成对」的意思；书页是手改的 HTML，Markdown 源已移除。

crates/ 的代码、注释、ARCHITECTURE.md、docs/ 与 docs/superpowers/ 仍为英文；只有本书 是中文。

目录

章节顺序跟随 Agent::agent_loop 执行路径：会话 → prompt 输入 → 压缩 → LLM 恢复 → 工具管线 → 领域工具 → 旁路系统。

# 章节 说明
1 存储与持久化 StoreRoot / JSON 文件存储、SQLite 会话库、领域消费者与 agent 持久化挂钩
2 Skill 注册表 SKILL.md 多根发现、prompt 摘要、load_skill、TUI slash（$ARGUMENTS）、<skill> 标签
3 持久记忆 按仓库切分的 ~/.tact/projects/<slug>/memory/ Markdown 记忆、类型、索引注入、save_memory / load_memory、旧全局目录迁移
4 系统提示 从 role / skills / guidelines / memory / 动态上下文组装系统提示，以及跨回合的缓存友好性
5 上下文压缩 micro_compact stub、compact_history 摘要、transcript / 大输出落盘
6 错误恢复 RecoveryState、传输退避重试、prompt-too-long 压缩、输出截断续写
7 工具系统 Tool trait、ToolRouter、registry.rs、ToolContext、路径安全、#[tool] 宏；§9 工具并行调度（ResourcePolicy、冲突判定、waves/barriers）
8 MCP 协议与集成 MCP 基础、协议流程、Tact 中的配置 / 握手 / 工具调用 / 动态更新 / 优雅关闭
9 Agent 生命周期 Hooks PreToolUse / PostToolUse、HookControl、注册 API、在工具管线中的位置
10 权限模型 能力风险分级、权限模式、白名单、TUI 审批流、shell 高风险检测、敏感路径守卫与脱敏（§12）、四个目标感知策略的逐例流程（§13）
11 任务与工具调度 一回合的三阶段流水线、权限 / hook 位置、ToolScheduleSummary 落库 — 非 Ch 19 持久任务；调度算法本身在 Ch 7 §9
12 子 Agent spawn_subagent 工具：嵌套 agent_loop、受限工具集、静态 prompt、权限继承、摘要返回
13 后台任务 background_run / check_background、tokio spawn、超时、启动修复
14 团队协作 .tact/team/ 队友名册、JSONL 收件箱、广播、计划审批 / 关机协议
15 Worktree 泳道 隔离 git worktree：create / list / status / run / events、索引与审计日志
17 桌面通知 macOS 原生通知（任务完成 / 步骤失败）、配置开关、平台缺口
18 Agent 主循环 收束章：agent_loop 回合、流式、cancel_flag、AgentUpdate、TUI TaskComplete
19 持久任务管理器 TaskManager、task_create / get / list / update、.tact/tasks/ 依赖
20 Agent 循环中的幻觉 LLM 编造文件、摘要和工具结果；压缩摘要编造案例；截断占位符引发的内容编造；缓解策略
21 配置 TOML/CLI 合并、ResolvedConfig、init() → tact_llm::init_provider
22 LLM Providers tact_llm 适配器、流式、thinking、user_id、余额查询
23 终端 UI tui crate、AgentUpdate / UserCommand 通道、tact-ui 接线
24 测试策略 Mock LLM、tact_host driver、TUI TestBackend、CI
25 Agent–TUI 协议 tact_protocol 消息类型、计划步骤生命周期、任务级状态迁移
26 工程问题与优化日志 已交付优化与 bugfix的倒序日志（现象 → 决策 → 指针）
27 Bash 沙箱 bash 的可选 OS 级沙箱：布尔开关、按平台选后端、bubblewrap 策略、降级与非覆盖范围
28 Agent Goal 跨 turn 的持久目标、Goal Runner、验收证据、预算/恢复、权限边界与 TUI；已实现

如何阅读

  • 常量、代码地图与类型名保留英文原文，便于直接对照源码。
  • 运行时顺序：第 1–11 章跟随 agent_loop 一回合；12–15 为工具族；Ch 18 收束主循环；19 深挖 TaskManager；20 幻觉模式；21–22 为启动与 UI；24 测试；25 协议状态机；26 为工程优化 / bugfix日志（有行为变更时按 AGENTS.md 追加）。
  • 压缩与恢复：上下文压缩、错误恢复。
