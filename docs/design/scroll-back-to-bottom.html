「回到最新」悬浮药丸

滚离底部时，在日志区最后一行靠右下停靠一行药丸；有新输出时多一段 New activity · 徽章。点它或按 esc 回到最新。

为什么靠右不居中：实时统计行是居中的，两条居中的行上下叠在一起会读成一坨（见下面 ✗ 那张）。停靠右侧就把两者的轴分开了 —— 左边是内容，右下是 chrome。

B 档（推荐）：提示挂在输入框上边框右端

不是新渲染单元 —— 就是 Block 的第三个 title（左边 input_box_title、中间语音标签已经在用同一个模式）。所以没有 band、没有 overlay，宽度不够时跟左侧 title 一起被 block 裁掉。

B 与 C 现在只差一件事：band 背景（C 有，B 没有 —— B 就是边框上的文字）。两者都能点：B 的命中矩形就是那串字形本身（照 cancel_area 那套，render_input_box 返回、host 记录），点它和按 esc 是同一个动作。位置差一行。

配色与文案

  • 新活动 / New activity → theme.muted_fg()（状态）
  • ↓ 回到最新 · esc / ↓ Back to bottom · esc → theme.warning（动作）
  • 为什么不用 theme.accent：输入框左边那行 ❯ Input (…) 和中间的 ⏺ Voice 已经是 accent 红了，第三个红字会读成标题的一部分。amber 是「这一层在动」的颜色（吉祥物也是它）。
  • 徽章不存在时连分隔符一起省略：↓ 回到最新 · esc。
  • 列数 < 70 时不画（会和左侧 title 挤在一起）。

Esc 是「退出当前视图状态」的梯子 —— 新加一级

slash 弹窗打开 → 关弹窗› 语音中 → 取消语音› 滚离底部 → 回到最新› Insert → 回 Normal› Normal → 清选区

「滚离底部」也是一种视图状态，所以这一级插在「退出 Insert」之上：滚离时按一次 esc 回底部，再按一次才退 Insert。药丸把 esc 写在脸上，所以是可发现的。另一个原因是 End 在 Insert 模式已经绑给输入光标了。

真正的难点不是药丸

  • 今天两套行为并存：工具卡 Resize 路径用 was_pinned 尊重你的滚动位置（agent.rs:283），而消息追加路径（8 处）无条件把你拽回底部。
  • 所以现在往上翻、来一条流式输出，你有时被弹走、有时不会 —— 药丸在这种状态下没有意义。
  • 先把「跟尾」策略收进 append_msg / extend_msgs 两个原语，删掉那 8 处无条件调用，药丸才成立。

状态只有两个

  • visual_top（已有）：usize::MAX = 跟尾；具体值 = 用户自己定的位置。
  • unseen: bool（新）：离开底部期间有新行到达 → 徽章。
  • 显示 = !is_log_pinned_to_bottom()（这个 helper 已经存在，且能同时认出 sentinel 和「手动滚到底」）。
