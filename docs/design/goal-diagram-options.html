B. 原生状态机（stateDiagram-v2）

状态机的标准画法：起点/终点、转移标签直接贴在弧线上，恢复信息放注记。

stateDiagram-v2
    direction TB
    [*] --> draft : /goal create
    draft --> queued : driver 立即续跑
    queued --> running : claim 到 lease

    running --> waiting_user : goal_request_input
    running --> paused : 预算耗尽 / Esc / pause
    running --> verifying : 完成提议
    verifying --> succeeded : 必需标准齐备
    verifying --> running : 自动标准未过

    state "running (idle)" as idle
    running --> idle : 本轮无可观察进展
    idle --> running : /goal resume
    waiting_user --> running : 回答后 /goal resume
    paused --> running : /goal resume
    waiting_user --> succeeded : /goal accept

    running --> failed : Stop hook 首轮拦截
    running --> cancelled : /goal cancel
    waiting_user --> cancelled : /goal cancel
    paused --> cancelled : /goal cancel

    note right of paused
        崩溃恢复：启动时（或运行中每 15s 对账）
        lease 过期或持有进程消失
        → Run 标 interrupted，Goal 落 paused
    end note
