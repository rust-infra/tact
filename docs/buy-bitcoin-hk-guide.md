## 一、持牌交易所（SFC 監管合規）

香港證監會（SFC）已正式實施虛擬資產交易平台發牌制度。以下是目前已獲牌或在港合規營運的選擇：

### 1. OSL（osl.com）
- **牌照**：SFC 第 1 類（證券交易）及第 7 類（自動化交易）持牌
- **特點**：首個獲 SFC 發牌的合規平台，支持 BTC、ETH 等主流幣
- **出入金**：支援 FPS、銀行轉賬（HKD），門檻約 HK$10,000 起
- **適合**：機構投資者、大額買家、重視合規的用戶
- **缺點**：上幣數量少，手續費偏高

### 2. HashKey Exchange（hashkey.com）
- **牌照**：SFC 持牌虛擬資產交易平台（自 2023 年 11 月起）
- **特點**：面向零售客戶（需通過資產測試），支援 BTC / ETH / USDT / USDC
- **出入金**：FPS 即時轉賬、銀行轉賬，最低入金 HK$1,000
- **適合**：散戶、想用 HKD 直接買幣的用戶
- **優點**：中文客服、App 體驗較好，法幣通道順暢

### 3. 比較：持牌 vs 非持牌

| 項目 | OSL / HashKey | Binance / Bybit |
|------|---------------|-----------------|
| SFC 監管 | ✅ 是 | ❌ 否 |
| 投資者保障 | ✅ 有（賠償基金機制） | ❌ 無 |
| HKD 直接入金 | ✅ FPS / 轉數快 | ❌ 需經 P2P 或第三方 |
| 幣種數量 | 少（主流幣為主） | 極多（數百種） |
| 手續費 | 較高（0.1%–0.3%） | 較低（0.01%–0.1%） |

## 二、國際交易所（香港仍可使用）

**⚠️ 注意：以下平台未獲 SFC 發牌，使用時需自行承擔風險。**

### 1. Binance（幣安）
- **網址**：binance.com（香港 IP 可訪問，但不可向香港用戶提供衍生產品）
- **買幣方式**：P2P 市場（用 HKD 買 USDT，再兌 BTC）、信用卡（手續費高）
- **優勢**：流動性最大、幣種最齊、手續費低
- **劣勢**：無 HKD 直接法幣通道（2023 年已退出香港市場）

### 2. Bybit
- **特點**：衍生品交易為主，現貨交易近年增長快
- **出入金**：支援信用卡、P2P（HKD 買 USDT）
- **適合**：習慣合約交易的用戶

### 3. Crypto.com
- **特點**：App 體驗好的國際平台，支援信用卡直接買幣
- **出入金**：Visa/Mastercard、銀行轉賬
- **優勢**：手續費透明，有 DeFi 錢包整合
- **劣勢**：HKD 通道不如持牌平台直接

## 三、支付方式詳解

### 1. FPS（轉數快 / Faster Payment System）—— 最推薦
- **時效**：即時到帳（24/7）
- **費用**：絕大部分免費
- **適用平台**：OSL、HashKey（直接入金 HKD）
- **操作**：銀行 App → FPS → 輸入平台提供的 FPS ID / QR Code → 完成
- **上限**：一般 HK$10,000–$500,000/日（視乎銀行）

### 2. 銀行轉賬（CHATS / 電匯）
- **時效**：1–3 個工作日
- **適用**：大額入金（>HK$100,000）
- **費用**：HK$15–$200 不等（視銀行及中轉行）
- **注意**：部分銀行可能會標記加密貨幣相關轉賬，建議先與銀行確認

### 3. 信用卡 / 扣賬卡
- **時效**：即時
- **費用**：手續費極高（2%–5%），不建議大額使用
- **適用**：緊急買幣、小額試水
- **注意**：部分香港銀行（如滙豐、中銀）可能會拒付加密貨幣交易

### 4. P2P（點對點交易）
- **平台**：Binance P2P、Bybit P2P
- **方式**：賣家將 USDT 鎖定，你用 FPS / 銀行轉賬付 HKD 給賣家
- **風險**：存在被凍結銀行卡風險（如收到來歷不明資金）
- **建議**：只與信譽良好、交易量大的賣家交易

### 5. 加密貨幣 ATM
- **地點**：香港有少量 Bitcoin ATM（旺角、銅鑼灣）
- **手續費**：極高（5%–10%）
- **適合**：極小額、講求匿名性的用戶

## 四、監管環境概覽（截至 2025 年）

### SFC 發牌制度
- **《打擊洗錢條例》修訂**：自 2023 年 6 月 1 日起，所有在香港營運的中央虛擬資產交易平台均須向 SFC 申領牌照
- **過渡期**：2024 年 6 月 1 日結束，未持牌平台須停止向香港用戶提供服務
- **零售開放**：持牌平台可向零售投資者（散戶）提供服務，但需進行知識評估及資產測試

## 五、稅務須知（香港居民）

### 好消息：香港不徵收資本增值稅（Capital Gains Tax）
- 個人買賣 Bitcoin 的收益 **無需繳納資本增值稅**
- 這是香港相比新加坡、美國、英國等地的重大優勢

### 但需注意
| 情況 | 稅務影響 |
|------|---------|
| 個人長期持有、低買高賣 | ❌ 不課稅（無 CGT） |
| 頻繁交易視作「營利事業」 | ⚠️ 可能被視為利得稅課稅對象 |
| 以加密貨幣收取薪金 / 報酬 | ✅ 需申報薪俸稅 |
| 公司持有加密貨幣進行交易 | ✅ 需繳利得稅（16.5%） |

### 建議
- 個人投資者：保留交易記錄即可，無需主動報稅
- 頻繁交易者：建議諮詢稅務顧問，以免被 IRD（稅務局）追討
- 使用持牌平台：交易記錄完整，方便日後查核

## 七、安全貼士（必讀）

### 🛡️ 帳戶安全
1. **必開 2FA（雙重驗證）** — 用 Google Authenticator 或硬件 Key（如 YubiKey），**不要用 SMS 驗證**
2. **API 管理** — 不用的 API Key 立即刪除，限制 IP 白名單
3. **密碼管理** — 使用 Bitwarden / 1Password 等密碼管理器，不要重用密碼

### 💼 儲存安全
| 儲存方式 | 安全級別 | 適合 |
|---------|---------|------|
| 交易所（持牌） | ⭐⭐⭐ | 小額、短期 |
| 軟件錢包（如 MetaMask、Trust Wallet） | ⭐⭐⭐⭐ | 中等金額 |
| 硬件錢包（如 Ledger、Trezor） | ⭐⭐⭐⭐⭐ | 大額、長期持有 |
| 冷錢包（離線生成 / 紙錢包） | ⭐⭐⭐⭐⭐ | 極大額 |

### 🚨 防詐騙
- **假平台**：只使用本指南推薦的平台，不要相信 Telegram / WhatsApp 群組的「投資專家」
- **釣魚短信**：不要點擊自稱「交易所」發送的連結，直接輸入官方網址
- **轉賬陷阱**：Bitcoin 交易是不可逆轉的，轉錯地址無法追回
- **高回報承諾**：任何保證回報的「理財產品」極大可能是龐氏騙局

### 🇭🇰 香港專屬注意事項
- **銀行凍卡風險**：使用 P2P 時有機會收到第三方詐騙資金，導致銀行戶口被凍結。建議盡量使用持牌平台的 FPS 通道
- **不設找續**：Bitcoin 轉賬時，手續費由發送方承擔，請留意網絡擁堵時 Gas 費用可能高企
- **保留記錄**：保留所有交易記錄、銀行轉賬單據，以備銀行或稅務局查詢
