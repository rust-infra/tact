# Historical design and implementation records

The `specs/` and `plans/` directories contain dated records from the work that
produced Tact. A file describes the repository at the date in its name.
Status words such as `draft`, `approved`, and `unverified` belong to that
record, not to the current release.

Use these records for design rationale and regression context. Use the current
code, [`ARCHITECTURE.md`](../../ARCHITECTURE.md), [`README.md`](../../README.md),
and the [book](../../book/index_zh.html) for current behavior.

When a record becomes a duplicate of a current reference page, delete it. When
it records a decision that current documents still depend on, keep it and link
it from the relevant current page.
