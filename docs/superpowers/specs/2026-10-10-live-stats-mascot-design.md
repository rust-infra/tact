# 实时任务统计行的「处理中」吉祥物 — 设计

**日期：** 2026-10-10
**状态：** 已实现（定案：**R1 两侧留白 + 成对字形翻转**）
**视觉稿：** `docs/design/live-stats-activity.html`（可交互：7 组图标 × 3 种朝向 × 3 条跑道 × 3 档速度）

## 问题

实时任务统计行（`Task stats:⏱ mm:ss · model · N tokens (…)`）在任务跑着的时候是**全屏唯一不动的东西**：
工具行有 `⠋` 转圈、thinking 卡片有时间轴、底栏有 spinner，只有这一行是一串静止的数字。用户问「这里能不能加个动画表示正在处理中」。

## 决策

在**实时统计行的两侧留白**里各放一只吉祥物，来回走动；掉头时**换成朝另一侧的同族字形**。

选择理由，按重要性：

1. **只动留白，不动文字。** 那一行每个格子都是数字（模型名、token 计数），任何横穿都会吃掉读数。这一行是**居中**的，所以两侧的留白天然是两条跑道。
2. **两侧镜像位相。** 右只 = 左只的镜像：离自己那侧的边一样远、朝反方向走，因此两只同时往里、同时掉头，看起来是一对。
3. **掉头 = 换字形。** 终端**不能镜像字形**（一个码位一个字形，没有 transform）。所以「掉头」是换成同族里朝另一侧的那个字形：`md-transfer_right` U+F0530 / `md-transfer_left` U+F0DA2。两者的 advance 与 `0` 完全相同（查过字体度量）→ 正好 1 列宽，跑道数学因此精确，也绝不会挤动文字。
4. **没有跑道就没有吉祥物。** 留白 < 4 列时整只不画。这就是全部的降级路径：**窄行就是没有留白可给的行使**，不需要第二个分支。文字溢出的行 `pad = 0`，自动没有吉祥物。
5. **同一个时钟。** 复用 `RenderCtx::spinner_frame`，与工具行 spinner、loading 占位同一拍，全屏动效同步。代价是它按**绘制帧**推进而不是按毫秒，所以流式输出密集时吉祥物会走快一点 —— 与现有 spinner 完全相同的取舍。
6. **`theme.warning` 而不是 `theme.accent`。** 那一行的文字已经是 accent 红，同色的吉祥物会读成句子的一部分。

## 关键取舍（被否掉的方案）

| 方案 | 为什么否掉 |
|---|---|
| 图标横穿文字 | 吃掉数字。不可接受。 |
| 文字跑马灯（滚动） | 计时器与 token 变成移动靶，而这一行的职责就是「不用翻日志就能看数」。仅在**文字放不下**时才有意义（那是另一个功能）。 |
| 对称动物（猫/熊猫/企鹅…）当默认 | 对称字形**不需要翻转**，来回跑都自然 —— 这是「动物 · 对称」组存在的理由，但它的方向信息为零，不如 `md-transfer_*` 一眼能看出朝向。 |
| 侧视动物（`md-dog_side` 右 / `md-bird` 左） | 需要**两只不同的动物**才能凑出左右，同一只换物种很怪。留作可选项（「动物 · 侧视」组）。 |
| 只在左侧留白跑 | 右侧留白白空着；两侧同跑是 0 行成本的（那本来就是空的）。 |
| 把吉祥物字形塞进 `task_stats_body` | 它是 live 行与 frozen 行的唯一来源，frozen 行的 `raw` 必须与绘制行逐字形一致（选择/点击映射依赖它）。动画只能在 live 分支。 |
| frozen 行也画吉祥物 | 那是已经结束的回合，动画会撒谎。 |

## 实现

- `crates/agent_tui_kit/src/render/stats_line.rs`：`MASCOT_RIGHT` / `MASCOT_LEFT` / `MASCOT_MIN_RUNWAY`、`mascot_step`（往返）、`mascot_cells`（两只的列与字形，纯函数），`render_live_stats_band` 末尾落笔。
- **tick 语义变更**：`App::spinner_frame` 与 `RenderCtx::spinner_frame` 从 `u8`（宿主已 `% 10`）改为**单调 `u32`**。转圈类动效自己取模（`bar.rs` 原本**没有**取模、依赖宿主，必须补上），吉祥物直接用长计数做往返。
- 文档：`docs/token_usage_schema.md` § Per-Turn Stats Line → "The mascot on the live row"；`book/23_chapter_tui_zh.md`；`book/26_chapter_issue_zh.md`。

## 已知风险

**字体覆盖。** 吉祥物是 PUA 字形，没有 Nerd Font 就是豆腐块。Tact 已经在用 `󰜼`（`[󰜼 打开]` 按钮），所以 Nerd Font 事实上已是既成要求 —— 但那是可点击的按钮，一个装饰性吉祥物渲染成豆腐更难看。
**暂不提供开关**（理由：与既有的 `󰜼` 一致，且开关要多改 6 个文件）。如果收到豆腐反馈，下一步加 `[ui] stats_mascot = true|false`，默认 `true`。

## 测试

- 纯函数：往返不跳端点、掉头恰好发生在两端、两只朝向永远相反、任何 tick 任何宽度都不碰文字列、留白不足时返回 `None`、退化跑道（0/1 列）与计数器回绕不 panic。
- 缓冲区：`the_live_row_walks_a_mascot_on_both_paddings` —— 那一行恰好两个吉祥物、都在文字区间之外、朝向相反、背景仍是 `theme.bg`。
- 既有用例适配：`stats_row_padding` 把吉祥物字形视为空白，否则「居中」用例会去量吉祥物的位置而不是文字的位置（改了之后用例仍过但**测的东西变了** —— 这是必须显式修掉的）。
